# just-bash 3.2.0: usable security and execution contract

**Pinned source.** This note is based on [commit 1fbde341d74ff7f933d9cead9a390a6ab65b5df3](https://github.com/vercel-labs/just-bash/tree/1fbde341d74ff7f933d9cead9a390a6ab65b5df3), package 3.2.0. It is an in-process TypeScript interpreter, not a VM or host shell. The upstream README calls it beta and recommends a full Vercel Sandbox/VM when arbitrary binaries or stronger isolation are required.

## Contract

- **Parsing, variables, loops.** AST shell support includes pipes, redirections, chaining, variables, positional parameters, globs, conditionals, functions, locals, loops and links ([README L117-L131](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L117-L131); [Bash.ts L1-L8](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L1-L8)). Each exec gets isolated env/functions/cwd; loop and recursion budgets apply ([README L25-L25](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L25-L25); [Bash.ts L673-L731](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L673-L731); [limits.ts L19-L35](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/limits.ts#L19-L35)). Parse errors return exit 2 ([Bash.ts L887-L901](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L887-L901)).
- **Virtual FS lifetime.** Default InMemoryFs has no disk access and is owned by the Bash instance; files survive calls on that instance, not instance disposal/restart ([README L191-L208](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L191-L208); [Bash.ts L328-L355](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L328-L355)). OverlayFs is copy-on-write; ReadWriteFs mutates a real root and must stay away from trusted code ([README L210-L243](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L210-L243)).
- **stdin and output.** exec accepts stdin as UTF-8 text or byte-shaped latin1; pipelines carry bytes ([Bash.ts L733-L751](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L733-L751); [Bash.ts L1166-L1189](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L1166-L1189)). Public results contain stdout, stderr and exitCode; binary output is decoded at the boundary ([Bash.ts L576-L594](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L576-L594)).
- **Abort.** AbortSignal is cooperative and checked at statement/command boundaries; abort/deadline maps to exit 124 ([README L179-L189](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L179-L189); [Bash.ts L858-L865](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L858-L865); [execution-scope.ts L364-L383](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/execution-scope.ts#L364-L383)).
- **Budgets and output.** Limits cover source, nested exec, commands/work, loops/call depth, input/live bytes, filesystem, archives/databases, deadline, strings/heredocs, FDs and aggregate output ([limits.ts L12-L147](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/limits.ts#L12-L147)). Normal defaults are liberal (1h, 256 MiB output, 1 GiB FS); hardened is opt-in (30s, 10 MiB output, 128 MiB FS) ([limits.ts L152-L256](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/limits.ts#L152-L256)). One ExecutionScope shares accounting across nested execution ([execution-scope.ts L40-L58](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/execution-scope.ts#L40-L58)); output overflow is exit 126 with sanitized stderr ([execution-scope.ts L228-L260](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/execution-scope.ts#L228-L260); [Bash.ts L867-L876](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L867-L876)).
- **Custom commands.** defineCommand receives fs/cwd/env/stdin/limits/exec, overrides built-ins, and is trusted by default. trusted:false selects the restricted boundary ([README L27-L78](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L27-L78); [custom-commands.ts L83-L104](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/custom-commands.ts#L83-L104); [Bash.ts L522-L553](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L522-L553)). Treat all custom commands as host authority.
- **Network.** Disabled unless network or secure fetch is supplied; curl is otherwise absent. Allow-lists enforce origin/path, methods, redirects and header transforms ([README L283-L337](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L283-L337); [Bash.ts L372-L377](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L372-L377); [Bash.ts L488-L493](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L488-L493)). Keep network off by default and never forward ambient credentials.
- **Threat boundary.** Upstream explicitly says there is no VM isolation; defense-in-depth is secondary/best effort, same-realm cached intrinsics cannot all be revoked, and worker WASM memory limits are not reliable. Python/JS are off by default ([README L629-L656](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/README.md#L629-L656); [Bash.ts L212-L241](https://github.com/vercel-labs/just-bash/blob/1fbde341d74ff7f933d9cead9a390a6ab65b5df3/packages/just-bash/src/Bash.ts#L212-L241)). It is suitable for bounded data transformation in a trusted process, not hostile tenant code.

## pi-world gaps and recommendation

The substrate research note identifies just-bash as a constrained virtual shell, not a replacement for Pi/Bun host shell ([pi-rlm-effect-v4-substrate.md](../pi-rlm-effect-v4-substrate.md)). Before integration pi-world must define:

1. Session-owned Bash lifetime and explicit shutdown; no restart durability unless pi-world persists/reconstructs the FS.
2. Separate shell capability, filesystem policy, network policy and custom-command authority.
3. Hardened limits, InMemoryFs, and Python/JavaScript/network disabled by default.
4. A bridge with explicit script/stdin/cwd/env/signal and independently bounded serialized results.
5. Concurrency semantics for shared files and serialized writes where needed.
6. Secret handling: keep credentials in policy-owned fetch transforms, never guest env/snapshots.
7. Outer process/container/VM isolation when adversarial code, hard memory bounds, or forcible cancellation is required.

**Decision:** integrate only as an explicitly named EnvironmentShell/JustBash capability. It provides usable virtual, bounded shell semantics, but is not secure execution against a malicious tenant without an outer isolation boundary.
