# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues in `aivv73/pi-world`. Use
the `gh` CLI for all operations.

## Conventions

- Create, read, comment on, label, assign, and close work through GitHub Issues.
- Infer the repository from the `origin` remote or pass
  `--repo aivv73/pi-world` explicitly.
- GitHub shares issue and pull-request numbers; resolve ambiguity before writing.
- PRs are not a triage request surface.

## When a skill publishes work

Create a GitHub issue. Specs use the configured `ready-for-agent` label when complete.

## Wayfinding

Wayfinder maps use `wayfinder:map`; children use GitHub sub-issues and the
matching `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, or
`wayfinder:task` label. Native issue dependencies are the canonical blocking
representation.
