# Project Knowledge

This is a single-context project.

## Before exploring

- Read the root `CONTEXT.md` and use its domain terms.
- Discover locally scoped Linked Specs before changing governed code.
- Read relevant `ARCH-*`, `GATE-*`, `REQ-*`, and `SPEC-*` records.
- Read relevant `CLAIM-*` records and preserve their load-bearing properties.

Linked Specs normally live in a `specs/` directory under the scope they govern.
Their absence does not block ordinary work or justify creating records. If a
governing record conflicts with requested work, stop and escalate rather than
overriding it.
